# Enterprise Infrastructure & DevOps Lab

Мой личный полигон и база знаний.

## Доступные руководства и мануалы:

* **[Развертывание SAP NetWeaver 7.52 SP04 ABAP на openSUSE Leap 15.3](./manuals/sap-netweaver-deployment/README.md)** — Обход конфликтов glibc 2.39+, тюнинг Shared Memory ядра и подмена FlexNet/SySAM лицензий базы Sybase ASE.

* **[Защита веб-сервера (Nginx + Fail2ban)](./manuals/nginx-fail2ban-security/README.md)** — Практическое руководство по настройке Rate Limiting, скрытию заголовков сервера и автоматической блокировке атакующих хостов без бюджета.

* **[Установка ГОСТ Р сертификата и настройка КриптоПро CSP 5.0 на Ubuntu 22.04](./manuals/cryptopro-gost-ubuntu/README.md)** — Разбор ручной установки сертификатов, привязки закрытых ключей к контейнерам, работы с хранилищами и разбор типовых ошибок без графической оболочки.

---
*Все проекты развернуты на собственном хосте Ubuntu 24.04 (20 Cores, 64 GB RAM) внутри KVM.*
