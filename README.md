# Enterprise Infrastructure & DevOps Lab

Практическая база знаний по администрированию и автоматизации enterprise-инфраструктуры.

Все представленные материалы основаны на реальном опыте эксплуатации и содержат готовые конфигурации, методы решения неочевидных проблем, выходящих за рамки стандартной документации.

## Доступные руководства и мануалы:

* **[Кластер Elasticsearch 7.17.27 с балансировщиком Nginx](./manuals/elasticcluster/README.md)** — Развёртывание отказоустойчивого кластера из 3 нод с гибридной архитектурой хранения (быстрые/медленные SSD) через `backup`-апстрим, общим NFS-репозиторием снапшотов и слиянием данных из изолированных БД через `_reindex`.

* **[Развертывание SAP NetWeaver 7.52 SP04 ABAP на openSUSE Leap 15.3](./manuals/sap-netweaver-deployment/README.md)** — Обход конфликтов glibc 2.39+, тюнинг Shared Memory ядра и подмена FlexNet/SySAM лицензий базы Sybase ASE.

* **[Защита веб-сервера (Nginx + Fail2ban)](./manuals/nginx-fail2ban-security/README.md)** — Практическое руководство по настройке Rate Limiting, скрытию заголовков сервера и автоматической блокировке атакующих хостов без бюджета.

* **[Установка ГОСТ Р сертификата и настройка КриптоПро CSP 5.0 на Ubuntu 22.04](./manuals/install-cryptopro-ubuntu/README.md)** — Разбор ручной установки сертификатов, привязки закрытых ключей к контейнерам, работы с хранилищами и методы отладки в CLI-режиме (без GUI).
